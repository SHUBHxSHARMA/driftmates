# Driftmates — concept site

A front-end prototype for Driftmates Adventure. Content is drawn from driftmates.com. The visual language follows the editorial luxury of marvelsofafrica.com: full-bleed photography, Playfair Display, cream pages, forest-green actions.

```bash
npm install
npm run dev
```

Open http://localhost:5173

Enquiry forms are visual only — they confirm on screen and do not send email yet.
Day-by-day lines on journey pages are an indicative flow for the pitch, not the operator’s final itinerary.
Photography is stand-in landscape imagery until the client supplies their own.
